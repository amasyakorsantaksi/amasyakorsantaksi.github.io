# Amasya Korsan Taksi

Amasya korsan taksi hattında terminal şehrin kendisinde değil Merzifon'dadır. Amasya merkezden havalimanı 51 kilometre, 42 dakika tutar; Suluova'dan 23 kilometredir. Sefer bulunamadığında Samsun'dan uçmak isteyenler için de araç çıkar.

Yeşilırmak kıyısındaki Yalıboyu otellerine giden yol dar ve tek yönlüdür, bu yüzden sürücü otelin en yakın noktasına kadar yanaşır. Kale ve kaya mezarları gezisinden sonra Borabay Gölü'ne geçmek isteyenler Taşova yönüne götürülür.
